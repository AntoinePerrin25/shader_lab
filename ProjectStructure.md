# Shader Lab Project Structure

## Directory Structure

### `/include/` - Header Files
- **`common.h`** - Contains shared data structures, constants, and function prototypes used across multiple modules. Includes logging system types, screen dimensions, and forward declarations.
- **`shader_manager.h`** - Declares the shader management system including shader discovery, loading, error handling, and preview generation functions.
- **`video_processor.h`** - Defines video processing capabilities including frame extraction from videos, texture buffer management, and synchronous video processing.
- **`ui_renderer.h`** - Contains UI rendering system declarations for the main interface, shader preview grid, and interactive elements.
- **`raygui.h`** - External Raylib GUI library header for advanced UI components.
- **`raylib.h`** - Main Raylib graphics library header providing rendering, input, and window management.
- **`raymath.h`** - Raylib math utilities for vector operations and mathematical functions.

### `/src/` - Source Files
- **`main.c`** - Entry point and main application loop. Handles initialization, input processing, drag-and-drop file loading, and coordinates between all modules.
- **`logger.c`** - Logging system implementation with timestamp support, consecutive message detection, and file output for debugging.
- **`shader_manager.c`** - Shader management implementation including automatic shader discovery, safe loading with error handling, and preview texture generation.
- **`video_processor.c`** - Video processing using FFmpeg for frame extraction, texture buffer management, and frame-by-frame video playback support.
- **`ui_renderer.c`** - UI rendering implementation including the main control panel, shader preview grid with dynamic sizing, and interactive buttons.

### `/lib/` - Libraries
- **`libraylib.a`** - Static Raylib library for linking.
- **`libraylibdll.a`** - Import library for dynamic Raylib linking.
- **`raylib.dll`** - Dynamic Raylib library for runtime.

### Root Files
- **`nob.c`** - Build system using the Nob (No Bullshit) build tool. Compiles all source files and links with Raylib.
- **`nob.h`** - Nob build system header with build utilities and macros.
- **`effect.fs`** - Default fragment shader file used as fallback when no other shaders are available.
- **`debug.log`** - Runtime log file generated by the logging system for debugging purposes.

### `/shaders/` - Shader Files
Contains fragment shader files (.fs, .glsl) that are automatically discovered and loaded by the shader manager.

### `/temp_frames/` - Temporary Video Frames
Temporary directory created during video processing to store extracted PNG frames from video files.

## Module Dependencies
- **main.c** depends on all other modules and coordinates the application
- **ui_renderer.c** depends on shader_manager for accessing shader data
- **video_processor.c** is independent and handles video processing
- **logger.c** is used by all modules for debugging output
- **common.h** provides shared definitions used by all modules
